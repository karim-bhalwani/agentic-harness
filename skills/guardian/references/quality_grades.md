# Quality Grades

> Generated and maintained by Guardian reviews and retrospectives.
> Each entry is append-only. Do not edit previous entries.

## Grading Scale

| Grade | Meaning | Criteria |
|-------|---------|----------|
| **A** | Ship-ready | 0 Critical/High findings, tests pass, docs current |
| **B** | Minor issues | 0 Critical, 1-2 High findings with clear remediation |
| **C** | Needs work | 1+ Critical or 3+ High findings |
| **D** | Major rework | Scope drift detected or spec coverage < 70% |
| **F** | Restart | Architectural misalignment or security vulnerability requiring redesign |
